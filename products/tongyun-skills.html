作品 · tongyun-skills

可用tongyun-skills

技能 Skills

Skill 素材库。格式遵循 Agent Skills，可用 Cursor、Codex、Claude，以及 npx skills 安装。

为谁

要在 Cursor、Codex、Claude 里用这些 skill，或用 npx skills 安装的人。

能干什么

  • tong-chart本地 Mermaid 出图（流程 / 架构 / 时序 / 甘特等），多主题，macOS · Windows · Linux。
  • tong-cover本地 Pillow 封面 / 刊头 / 简报 / 金句卡，按星期换色。
  • tong-git项目仓状态，按需提交，推到 Gitee / GitHub / CNB。
  • tong-humanize去 AI 味改写：扫描套话 / 三毒 / 标点，按栏目交稿。
  • tong-mysql-ro只读 MySQL：SELECT / SHOW / DESCRIBE，强制 LIMIT，凭证本地填。
  • tong-mysql-write写库 DML：默认预览，确认后 --apply 并落回滚 SQL。不做 DDL。
  • 仓库里怎么放skills/ 每个 skill 一个目录。templates/ 是新建用的脚手架，不是 skill。scripts/ 做校验、打包和脚手架。docs/ 写怎么写、怎么打包。playground/ 是本机网页，用来试 skill，不装到系统。
查看仓库 →

仓库现为私有，自用。README 没有写 Release。对外安装说明以仓库 README 为准，不承诺公开安装源。

格式说明见 Agent Skills。新 skill 按 AGENTS.md 加，不要往这个仓库塞无关内容。细节也看 docs/authoring.md。

各 skill 目录：tong-chart、tong-cover、tong-git、tong-humanize、tong-mysql-ro、tong-mysql-write。

test_skills.py 会校验 SKILL.md，并跑每个 skill 的 tests/。不用先装到 ~/.cursor/skills。tong-cover 的测试需要 Pillow（pip install pillow）。本机网页只绑 127.0.0.1，README 写的地址是 http://127.0.0.1:8765 。

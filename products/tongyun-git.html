桌面 Git tongyun-git

独立的桌面 Git 客户端，用法靠近 IntelliJ IDEA 自带的 Git 面板，提交说明可以请模型起一稿。

为谁

想在编辑器外面看改动、暂存、提交和推拉的人。

能干什么

  • 打开仓库输入路径、用系统对话框选目录，或把文件夹拖进窗口。还不是仓库的目录可以一键 git init。
  • 对照改动工作区和暂存区分开看。可以按文件、按代码块，或按行暂存。丢弃前会再确认，并留一小段可撤销的快照。
  • 提交支持修正上一次提交。可以用 KIE、OpenAI 兼容接口或本机 Ollama 生成 Conventional Commits 说明。密钥放在系统钥匙串里。
  • 分支和历史切换、新建分支，看提交树。
  • 推拉Fetch、Pull、Push。操作日志记下命令和输出，并打码地址里的凭据。

# 橦云学习

**一句话：** 给自己用的学习站点。背单词、练习和复习是站内模块。

**为谁：** 想在一个地方跟打、默写，并看今天该复习什么的人。

**能干什么：**
- **背单词与练习：** 跟打、默写、自测、看词拼写，按记忆曲线混在一起学。
- **讲解：** 单词记忆法，以及文章里句子的讲解，走同域的学习服务。
- **错词复习卷：** 从错词本选题，做成填空、选择或英译中，在本地判分。
- **学习看板：** 今日任务、待复习、卡点和各科统计。页面按手机优先来排。

**技术栈：** Nuxt 4、Vue 3、TypeScript。更早的 FastAPI 学习服务收在仓库的 legacy 目录。前端基于 TypeWords 二次开发，许可 GPL-3.0。

**仓库：** https://github.com/dangzhuotong/tongyun-learn

**安装 / Release：** 还没有 Release。本机需要 Node.js 24 和 pnpm。在仓库里执行 pnpm dev，默认打开 http://localhost:5567/learn/ 。

**许可：** GPL-3.0

**状态：** 打磨中

可用tongyun-api

橦云接口 tongyun-api

在桌面上调试 API。接口写成仓库里的纯文本，用 Git 管理，不绑云端账号。

为谁

希望用例留在自己的项目仓库里，并能用分支和 Pull Request 看改动的人。

能干什么

  • 两种文本可读 IntelliJ 的 .http / .rest，也读 tongyun-collections 里一个接口一个文件的 JSON。
  • 直接发请求用 Rust 发出去，不走浏览器的跨域限制。请求头、认证和正文都可以改。
  • 多个标签同时改几条请求。可以断言状态码、耗时、JSON 路径和响应头。
  • 抽出变量从响应里取出字段，写进当前环境，方便登录之后接着调下一个接口。
  • 导入和示例能导入 cURL、Postman Collection v2.1、OpenAPI 3.0 和 .http。可以生成 cURL、JavaScript、TypeScript、Python、Go、Rust 示例。私有变量放在被 Git 忽略的文件里。
